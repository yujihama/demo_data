# 6.consolidation — 連結決算業務データ一式（FY2025）

デモA株式会社グループの**連結決算業務**（決算財務報告プロセス／FCRP・S05連結決算システム関連統制の背景業務）を想定した、網羅的かつ相互整合するダミーデータセット。

- **対象期間**：FY2025（2025年4月1日〜2026年3月31日）／年度決算（Q4）を中心に収録
- **単位**：千円（Demo-A (Thailand) の現地帳簿は千THB）
- **生成スクリプト**：[`_scripts/consolidation_model.py`](../_scripts/consolidation_model.py)（数値の単一情報源・検算付き）、`_scripts/gen_consol_a_master_packages.py`、`_scripts/gen_consol_b_consolidation.py`

## 意図的に仕込んだ「リアリティ」ポイント

1. **未達取引**：DA-HQ→DATRの期末直前出荷6,200千円が買い手未着。照合表で差異検出→未達整理仕訳（CNS-FY25-004）で解消。未達分の未実現利益1,240千円も消去対象。
2. **在外子会社の換算**：BSは期末CR4.20、PLは平均AR4.10、資本金は取得時HR3.00。CTA期末202,832千円（当期増+82,832）はプラグとして算定過程を明示。JPY建て借入はDAT側で換算差益が発生。
3. **のれんと非支配株主持分**：DATR 80%取得（2019/4）でのれん160,000千円・10年償却。NCIは期首117,920→損益+34,080→配当△10,000→期末142,000で完全ロール。
4. **未実現利益の税効果**：42,800千円×30.6%の繰延税金資産を連結固有の一時差異として計上（手動仕訳・EUC計算シート付き）。
5. **提出プロセスの履歴**：回収状況管理表はQ1〜Q4の再提出履歴（Q1物流・トレーディング、Q2東北・物流、Q3東北）を既存のS05往復ログと同一内容で保持。Q4は全社初回PASS。

## 数値の内部整合（機械検算済み）

`consolidation_model.py` 実行時に以下をアサーションで検証している。

- 全社・全期（期首/期末）のBS貸借一致、利益剰余金ロール（期首＋当期純利益−配当＝期末）
- 固定資産・棚卸資産・販管費内訳と本表の一致
- 連結仕訳の各伝票貸借一致、連結精算表・連結BSの貸借一致
- 連結CFの現金増減と連結BS現金増減の一致
- 連結売上高 38,001,000千円（≒公表値380億円）、営業利益 2,977,200千円、親会社株主帰属当期純利益 1,938,293千円
