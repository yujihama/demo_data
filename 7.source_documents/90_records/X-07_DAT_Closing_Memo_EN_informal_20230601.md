## 1. Monthly closing (internal)

| Day | Task | Owner |
|---|---|---|
| WD+1 | Close production / inventory data | Accounting Staff |
| WD+2 | Post accruals (utilities, salary, provident fund) | Accounting Staff |
| WD+3 | Bank reconciliation | Accounting Staff |
| WD+5 | Review by Accounting Manager | Accounting Manager |
| WD+7 | Send monthly TB to HQ (Japan) | Accounting Manager |

Note: Thai statutory monthly closing takes about 7 working days. HQ asks for 5 WD for the
quarterly package — this is tight. Discussed with HQ several times.

## 2. Quarterly consolidation package

1. Download TB from SAP.
2. Fill BS / PL sheets in the package file (THB thousand).
3. Fill inter-company balance and transaction sheets.
   - **Important**: use the correct company code (DA-HQ / DA-TB / DA-LOG / DATR).
   - HQ complained about wrong company codes in FY2022.
4. Fill inventory sheet — need to split "purchased from group companies".
5. Fill fixed asset / provision / tax sheets.
6. Sheet 14 (subsequent events): write "N/A" if nothing. HQ requires this.
7. Manager review → upload to S05.
8. Fix validation errors and re-upload.

## 3. JP-GAAP adjustments (the difficult part)

These items differ between Thai practice and the group accounting policy.
No written guidance from HQ — we estimate based on last year's package.

| Item | Thai practice | Group policy (as understood) | How we handle it |
|---|---|---|---|
| Depreciation useful life | Thai Revenue Code rates | Japanese statutory useful life | Recalculate manually in Excel |
| Severance pay (retirement) | Thai Labour Protection Act | Japanese retirement benefit accounting (principle method) | Ask HQ each year |
| Inventory write-down | Not usually recorded | Group policy applies | Follow HQ instruction (received verbally) |
| Allowance for doubtful accounts | Tax-based | Group policy applies | Follow HQ instruction |

## 4. FX

We report in THB. HQ converts to JPY. We just need to write the FX rate used for any
foreign-currency transaction in the inter-company sheets.
