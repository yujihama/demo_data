## 2. 月次決算・締め処理（No.1）

**対象**：FCRP-001　**対象者**：経理部課長 高橋 美咲（E0012）

### 2-1. 業務の流れ（聴取した内容）

| 工程 | 内容 | 聴取したポイント |
|---|---|---|
| 締め前確認 | 前月の決算が承認済であること、各部門からのデータ受領を確認 | 「各部門のデータは翌1〜2営業日に届く。製造本部が遅れることが月に1回程度ある」 |
| モジュール締め | SD→MM→CO→FI-AA→FI の順で締める | 「順序は決まっている。過去にMMを先に締めてCOの原価計算がやり直しになったことがある」 |
| 決算整理仕訳 | 引当金の月次計上、前払費用の按分等を入力 | 「9種類の定型仕訳がある。金額は計算シートから転記する」 |
| 勘定照合 | 主任・担当が実施、課長がレビュー | 「差異は100千円以上を調査対象としている」 |
| 増減分析 | 前月比±15%かつ10,000千円以上を説明対象 | 「閾値は要領に書いてある。実務でもそのとおり運用している」 |
| チェックリスト | 45項目に実施日・実施者・結果を記録 | 「45項目は数年前に整理したもの。決算業務規程には32項目と書いてあるが、実態は45項目」 |
| 承認 | 経理部長が稟議WFで承認 | 「部長はチェックリストの例外欄を必ず見る」 |

### 2-2. 規程との乖離（重要）

> **決算業務規程（R17 v3.0、2019年改訂）との乖離**
>
> - チェックリストの項目数：規程は「32項目」、実態は「45項目」
> - 連結決算：規程は「Excelの連結精算表」を前提としているが、実態は連結決算システム（S05）
> - 開示：規程に開示システム（S06）の記載がない
>
> 高橋課長のコメント：「規程は正直、見ていない。S05を入れた2022年に直すべきだったが、
> 導入対応で手一杯だった。実務はチェックリストと手順書（F-01）で回している」

**評価上の取扱い**：業務記述書は実態に基づき作成し、規程との不一致を明記する。
本件はELC-006（規程の年次見直し）の不備候補として内部監査室へ報告済。

## 3. 勘定残高照合（No.2）

**対象**：FCRP-001　**対象者**：経理部主任 中村 真理（E0014）、担当 小川 由紀（E0015）

### 3-1. 聴取内容

| 項目 | 内容 |
|---|---|
| 対象勘定 | 要領（F-05）に12勘定が定められている |
| 様式 | 預金・売掛金・買掛金・棚卸資産・固定資産・借入金は標準様式（F-06）がある |
| **様式がない勘定** | **未払金・未払費用、仮払金・仮受金、GL–補助元帳の全般照合は標準様式がない** |
| 実際の運用 | 「様式がない3つは、私（石井）が自分で作ったExcelでやっている。個人フォルダに置いている」（石井 健） |
| 差異の許容基準 | 1件100千円未満。「100千円以上は当月中に解消するルール」 |
| レビュー | 主任→課長の順。「レビュー印はExcelのセルに名前を入れる形」 |

### 3-2. 識別した事項

- **標準様式が未整備の3勘定**について、照合の観点（何と何を突合するか）が担当者に依存している。
- 石井担当が作成したExcelが**個人フォルダに保管**されており、他者がアクセスできない。
  担当者の不在時に照合が実施できないリスクがある。
- EUC統制の観点からも、共有フォルダへの移管が必要（F-32 No.8として記録）。

## 6. 会計上の見積り：棚卸資産評価損（No.5）★重要

**対象**：FCRP-003 / PLC-I-004　**対象者**：経理部課長（管理会計）伊藤 健太（E0013）

> **本節は、算定要領（F-14）が存在しないため、業務記述書の唯一の文書根拠となる。**

### 6-1. 聴取した算定ルール（口頭で運用されているもの）

| No | ルール | 聴取した内容（原文に近い形で記録） |
|---|---|---|
| ① | 滞留の判定 | 「回転期間が12か月を超えたら滞留とみなす。回転期間は在庫金額÷（過去12か月の払出金額÷12）で計算する」 |
| ② | 評価減率（12か月超） | 「12か月超24か月以下は帳簿価額の50%を落とす」 |
| ③ | 評価減率（24か月超） | 「24か月を超えたら100%落とす。実質的に価値がないという判断」 |
| ④ | 陳腐化 | 「顧客が生産を終了した部品や、設計変更で使えなくなった部品は、期間に関係なく100%落とす。営業や技術から連絡が来る」 |
| ⑤ | 正味売却価額 | 「売れる見込みがあるものは、売れる価格まで落とす。年に1〜2件くらい」 |
| ⑥ | 払出のない品目 | 「1年間まったく払出がないものは、最終払出日からの経過月数で判定する」 |

### 6-2. ルールの出所と継続性

- 伊藤課長：「このルールは**私が着任した2018年から変わっていない**。
  前任者（現在は退職）から引き継いだ。**どこにも書いていない**」
- 「監査法人からは毎年『文書にしてほしい』と言われている。作らないといけないとは思っている」
- 「回転期間12か月というのは、当社の製品ライフサイクル（自動車部品で3〜5年、
  半導体装置部品で1〜2年）を考えると妥当だと思っている。根拠を聞かれると
  『経験的にこの辺り』としか言えない」

### 6-3. 文書間の不整合

| 文書 | 記載 | 実態との一致 |
|---|---|---|
| 在庫管理規程（R14）第13条 | 「滞留在庫の判定基準は別途定める」 | 参照先の文書が**存在しない** |
| 月次決算チェックリスト No.25 | 「滞留在庫（**180日超**）の評価減検討」 | **不一致**（実態は12か月＝約365日） |
| 月次決算チェックリスト No.14 | 「棚卸資産評価損の検討」（日数の記載なし） | 判定基準が不明 |
| 会計方針マニュアル（C-03）3-2 | 「判定基準及び切下げ率はF-14による」 | 参照先の文書が**存在しない** |

伊藤課長：「チェックリストの180日は、たぶん**もっと前のルールが残っている**。
私が着任する前は180日だったのかもしれない。今は誰も180日では見ていない」

### 6-4. 評価上の結論

- 統制自体は**一貫した基準で運用されている**（2018年以降変更なし）と認められる。
- ただし、**判定基準を定めた文書が存在しない**ため、
  - 統制のデザインの妥当性を文書により確認できない
  - 担当者の交代時に同一の基準が維持される保証がない
  - 文書間（R14、C-03、チェックリスト）に不整合が残る
- 業務記述書には「**本業務に関する算定要領は存在せず、経理部（管理会計課）の
  運用ルールにより実施されている**」旨を明記する。
- ELC-006（規程の年次見直し）及びFCRP-003の評価において、この状態を考慮する。
