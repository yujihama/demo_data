## 1. 統制区分の略号

| 略号 | 正式名称 | 内容 | 統制ID体系 |
|---|---|---|---|
| ELC | Entity Level Control（全社的な内部統制） | COSO6要素に基づく全社レベルの統制 | `ELC-NNN` |
| PLC | Process Level Control（業務プロセス統制） | 個別業務プロセスに組み込まれた統制 | `PLC-{S/P/I}-NNN` |
| PLC-S | 〃（販売プロセス） | 受注〜売上計上〜入金消込 | `PLC-S-NNN` |
| PLC-P | 〃（購買プロセス） | 購買依頼〜発注〜検収〜支払 | `PLC-P-NNN` |
| PLC-I | 〃（在庫・原価プロセス） | 入出庫〜棚卸〜原価計算〜評価 | `PLC-I-NNN` |
| FCRP | Financial Close and Reporting Process（決算・財務報告プロセス） | 月次〜連結〜開示 | `FCRP-NNN` |
| ITGC | IT General Control（IT全般統制） | アクセス・変更・運用・外部委託 | `ITGC-{AC/CM/OM/EM}-NNN` |
| ITAC | IT Application Control（IT業務処理統制） | システムに組み込まれた自動統制 | `ITAC-NNN` |

| 略号 | 領域 | 主な統制 |

## 4. 文書番号の体系

### 4-1. インプット文書（本ディレクトリ）

| 接頭辞 | 領域 | 例 |
|---|---|---|
| `G-nn` | 共通基盤 | G-05 決裁権限一覧表 |
| `E-nn` | 全社的内部統制（ELC） | E-13 不正リスク評価要領 |
| `C-nn` | 全社的な決算・財務報告プロセス | C-05 連結決算マニュアル |
| `F-nn` | 決算・財務報告プロセス統制 | F-12 貸倒引当金 計上基準・算定要領 |
| `X-nn` | 運用実績・記録 | X-06 業務ヒアリング記録 |

### 4-2. 規程

`R01`〜`R37`。規程管理台帳（G-02）を正とする。R09・R10・R20・R32〜R35は欠番。

### 4-3. 帳票・様式

`F-{プロセス略号}-{連番}`。帳票・様式一覧（G-10）を正とする。

| プロセス略号 | 対象 |
|---|---|
| SLS | 販売 |
| PUR | 購買 |
| INV | 在庫・原価 |
| FCR | 決算・財務報告 |
| ELC | 全社 |
| IT | 情報システム |

### 4-4. ファイル命名規則

```
{文書ID}_{文書名}_{版数}_{施行日}.{拡張子}
例）E-01_倫理綱領_v3.0_20230401.pdf
```

版数・施行日をファイル名に持たせることで、規程の陳腐化が一覧で可視化される。

## 5. J-SOX関連用語

| 用語 | 定義 |
|---|---|
| 整備状況評価 | 統制のデザインが有効かを評価する手続。ウォークスルー等による |
| 運用状況評価 | 統制が意図したとおりに運用されているかを評価する手続。サンプルテスト等による |
| ウォークスルー | 1件の取引を開始から財務諸表への計上まで追跡し、統制の存在を確認する手続 |
| ロールフォワード | 期中評価から期末までの間に統制に変更がないことを確認する手続 |
| キーコントロール | リスクを直接的・網羅的に低減し、評価が可能な統制。評価対象となる |
| 補完統制 | キーコントロールが機能しない場合に、リスクを低減しうる代替的な統制 |
| 重要な不備 | 財務報告に重要な影響を及ぼす可能性が高い内部統制の不備 |
| 判断保留 | エビデンス不足により統制の有効性を判定できない状態 |
| 3点セット | 業務フローチャート・業務記述書・RCMの3文書 |
| RCM | Risk Control Matrix。リスクと統制の対応関係を一覧化した文書 |
| CUEC | Complementary User Entity Controls。委託先のSOC1報告書が前提とする利用者側統制 |
| SOC1報告書 | 受託業務に係る内部統制の保証報告書。Type I（デザイン）とType II（運用）がある |
| EUC | End User Computing。利用部門が自ら作成・運用するExcel等のツール |
| トップサイドエントリー | 通常の業務システムを経由せず、決算時に総勘定元帳へ直接入力される仕訳 |

## 6. 会計用語

| 用語 | 定義・当社での取扱い |
|---|---|
| 一般債権 | 経営状態に重要な問題が生じていない債務者に対する債権。貸倒実績率法により引当 |
| 貸倒懸念債権 | 経営破綻には至っていないが、債務の弁済に重大な問題が生じている債務者に対する債権 |
| 破産更生債権等 | 経営破綻又は実質的に経営破綻に陥っている債務者に対する債権 |
| 滞留在庫 | 一定期間払出しのない在庫。当社では回転期間基準により判定（F-14参照） |
| 減損の兆候 | 資産又は資産グループに減損が生じている可能性を示す事象 |
| グルーピング | 減損会計における、キャッシュ・フローを生み出す最小単位への資産のまとめ方 |
| DTA | Deferred Tax Assets（繰延税金資産） |
| 企業分類 | 繰延税金資産の回収可能性の判断における分類（1〜5）。当社は分類2 |
| CTA | Cumulative Translation Adjustment（為替換算調整勘定） |
| NCI | Non-Controlling Interests（非支配株主持分） |
| 未実現利益 | グループ内取引により付加された利益のうち、期末在庫等に含まれ外部に実現していないもの |
| CR / AR / HR | 決算日レート（Current Rate）／期中平均レート（Average Rate）／取得時レート（Historical Rate） |

## 7. 本文書セットの表記ルール

- 金額は特記なき限り**千円**単位、税抜。
- 日付は原則 `YYYY年M月D日`（ファイル名は `YYYYMMDD`）。
- 人物は「役職 氏名（社員番号）」の形式で表記する（例：経理部長 佐藤 一郎（E0011））。社員番号は
  `1.master_data/employees.xlsx` を正とする。
- 「★」を付した記載は、**未解決の課題又は文書間の不整合**を示す。ELC-006（規程の年次見直し）の評価インプットとなる。
