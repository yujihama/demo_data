# 7.source_documents — RCM／業務記述書 作成インプット文書ラインナップ（計画）

本ディレクトリは、**全社的内部統制（ELC）／全社的な決算・財務報告プロセス／決算・財務報告プロセス統制（FCRP）** の
**RCM および業務記述書を作成するための「インプット側」ドキュメント**を格納する。

既存の `4.evidence/`（＝統制が運用された結果の記録）、`5.test_results/`（＝監査人の調書）に対し、
本ディレクトリは **「そもそも何をどう統制すると定めているか」を示す一次資料**（規程・マニュアル・要領・様式・ワークシート・体制表）を扱う。

> **前提**：本ラインナップは架空会社「デモA株式会社」（[0.profile/company_profile.md](../0.profile/company_profile.md)）を対象とする。
> すべての文書が完備している必要はない。むしろ**意図的な欠落・不整合を設計に織り込む**（第6章参照）。

---

## 1. 設計の考え方（成果物から逆算する）

インプット文書は「あると良さそうなもの」を並べるのではなく、
**RCM／業務記述書の各記載項目を、どの文書が埋めるか**から逆算して定義する。

### 1-1. RCMの記載項目 → 必要なインプット

| RCM の列 | 主たるインプット文書 |
|---|---|
| プロセス／サブプロセス | 決算業務規程、決算スケジュール、各手順書 |
| リスクの内容 | リスク管理規程、全社リスクアセスメントシート、不正リスク評価シート、トップリスク一覧 |
| 関連勘定科目 | 勘定科目一覧、財務諸表・勘定科目別残高一覧、会計方針マニュアル |
| アサーション | アサーション定義集、会計方針マニュアル |
| 統制の内容 | 各規程・マニュアル・業務要領（条文レベル） |
| 統制主体（部署・役職・担当者） | 詳細組織図、業務分掌表、職務権限規程、決算業務分担表 |
| 統制の頻度 | 決算カレンダー、チェックリスト、会議体一覧 |
| 予防的／発見的・手作業／IT自動 | 手順書、システム構成図、システム操作手順書 |
| キーコントロール判定 | J-SOX評価範囲決定資料、評価実施要領 |
| 統制の証跡 | 帳票・様式一覧、ワークシート様式、システムログ仕様 |
| 評価手続・サンプル件数 | J-SOX評価実施要領（サンプリング基準・不備判定基準） |

### 1-2. 業務記述書の記載項目 → 必要なインプット

| 業務記述書の項目 | 主たるインプット文書 |
|---|---|
| 業務の目的 | 各規程の「目的」条文 |
| 対象範囲・関連部署 | 業務分掌表、詳細組織図、決算体制図 |
| 業務の流れ（トリガー→処理→アウトプット） | 業務手順書、フローチャート、システム操作手順書 |
| インプット／アウトプット帳票 | 帳票・様式一覧、各ワークシート様式（ブランク版） |
| 使用システム・画面 | システム構成図、データフロー図、Tコード一覧 |
| 承認・レビュー（誰が何を） | 職務権限規程・決裁権限一覧表、ワークフロー設定情報 |
| 実施頻度・期限 | 決算スケジュール、締めカレンダー |
| 例外処理・イレギュラー対応 | 手順書の例外条項、稟議規程、緊急時対応要領 |
| 関連規程 | 規程体系図・規程管理台帳 |

### 1-3. 文書のレイヤー

| レイヤー | 内容 | 例 |
|---|---|---|
| **L0 共通基盤** | 3領域すべての前提となる文書 | 組織図、職務権限規程、規程体系図、評価範囲決定資料 |
| **L1 方針・規程** | 取締役会・経営会議で承認される最上位ルール | 内部統制基本方針、経理規程、連結決算規程 |
| **L2 マニュアル・要領** | 規程を実務手順に落としたもの | 月次決算手順書、減損適用要領、連結決算マニュアル |
| **L3 様式・ワークシート** | 実際に記入する器（**ブランク版**） | 勘定照合シート、貸倒引当金計算シート、連結パッケージ |
| **L4 台帳・体制表** | 継続管理される一覧 | 規程管理台帳、EUC台帳、決算業務分担表 |

`4.evidence/` にあるのは L3 の**記入済み実物**と L4 の**運用実績**。本ディレクトリは主に **L0〜L3 のブランク／定義側**を作る。

## 7. 意図的に設計する情報ギャップ

「すべての情報が揃っていなくてよい」という前提を、**ランダムな欠落ではなく意図的な設計**として織り込む。
これにより「不完全なインプットからRCM／業務記述書を組み立てる」という実務に近い状況を再現できる。

| # | ギャップの型 | 具体的な仕込み方 | 作成時に生じる論点 |
|---|---|---|---|
| GAP-1 | **規程の陳腐化** | C-02 決算業務規程の最終改訂を2019年とし、S05連結決算システム導入（2022年）前の手順のままにする | 規程と実態が不一致 → 業務記述書は実態ベース、ELC-006（規程の年次レビュー）の不備候補 |
| GAP-2 | **権限基準の不整合** | F-09 仕訳承認権限表の金額基準を、G-05 決裁権限一覧表（R18別表）と食い違わせる | どちらが正か判定できない → RCMの「統制主体」が確定しない |
| GAP-3 | **要領のない様式** | F-15 棚卸資産評価損計算シートは様式のみ存在し、F-14 算定要領を作成しない（＝実務は口頭伝承） | 統制の記述根拠がヒアリング（X-06）のみになる |
| GAP-4 | **様式のない要領** | F-05 勘定残高照合実施要領はあるが、F-06 照合シート様式の一部（仮勘定・GL-補助元帳）を欠く | 証跡列が埋まらない |
| GAP-5 | **根拠資料の添付ルール未整備** | F-22 見積りレビュー要領に「根拠資料の添付」を明記 → 既存の **FCRP-003（貸倒引当金の根拠資料未添付）** が規程違反として説明可能になる | 既存の仕込み不備と整合 |
| GAP-6 | **子会社側の未整備** | X-07 子会社決算手順書は東北のみ作成し、タイは英文の簡易メモのみ | グループ統一会計方針（C-06）の遵守状況が評価できない |

> 文書セット全体の一貫性が高まる。


**ファイル名**：`{ID}_{文書名}_{版数}_{施行日}.{ext}`
例）`E-01_倫理綱領_v3.0_20230401.pdf` / `F-13_貸倒引当金計算シート_v1.2_20240401_blank.xlsx`

**版数・施行日をファイル名に持たせる**ことで、GAP-1（規程の陳腐化）が一覧で可視化される。

**形式の使い分け**

| 形式 | 用途 |
|---|---|
| PDF | 規程・方針・議事録（＝改訂されない確定版） |
| xlsx | 様式・ワークシート・台帳・一覧表（＝記入する器、機械可読が必要なもの） |
| docx | マニュアル・手順書・要領（＝改訂を前提とする文書） |
| md | 定義書・用語集（＝差分管理したいもの） |
